# 상세 교재 — 처음부터 설계 문제까지

2026-09-16 확장판. SAA-C03 준비를 중심으로 작성한 한국어 자체 교재다. 공식 시험 문제나 공식 인증 교재는 아니다. 숫자로 된 서비스 한도·요금은 변할 수 있어 외우기 전에 공식 문서를 확인한다.

## 교재를 사용하는 방법

1. 한 장을 읽기 전에 제목만 보고 아는 내용을 3줄 적는다.
2. 설명과 예제를 읽고 요구사항이 바뀌면 답이 달라지는지 생각한다.
3. 장 끝의 확인 질문에 문서를 닫고 답한다.
4. 문제집에서 관련 문항을 푼다. 답을 맞혔어도 다른 선택지를 제외하지 못하면 다시 공부한다.
5. 공식 출처에서 조건과 예외를 확인한다.

이 자료만으로 모든 서비스의 세부 기능을 다루지는 않는다. [범위 대응표](12-review.md)의 추가 학습 항목까지 공식 가이드와 대조한다. AWS 계정 없이 가능한 실습을 먼저 제공하며 실제 클라우드 리소스를 자동 생성하지 않는다.
