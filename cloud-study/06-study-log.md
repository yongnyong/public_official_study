# 매일 학습 기록

아래를 복사해 날짜별 파일로 저장한다. 체크는 실제 공부한 뒤 한다.

```text
날짜:
공부 시간:
오늘 목표:
읽은 공식 문서:

내 말로 설명한 개념 3개:
1.
2.
3.

직접 만든 결과물:
헷갈린 개념:
내일 첫 번째 할 일:
```

## 주간 점검

- [ ] 용어를 번역하는 수준을 넘어 예시로 설명했다.
- [ ] 요구사항이 바뀌면 서비스 선택이 달라지는 이유를 설명했다.
- [ ] 실제 실행한 것과 설계만 한 것을 구분했다.
- [ ] 비용과 권한을 함께 검토했다.
- [ ] 기억한 문제 대신 새로운 문제로 확인했다.
