## 추천 목표

- 학습: Cloud Practitioner 수준의 기초부터 시작.
- 주 자격증 목표: **AWS Certified Solutions Architect – Associate(SAA-C03)**.
- 기초 자격증 자체가 필요하면 CLF-C02를 먼저 취득. 필수 선행 자격증으로 가정하지 않는다.
- 후속 목표: 클라우드에서 모델 배포·운영을 경험한 뒤 Machine Learning Engineer – Associate 검토.
- 오늘은 계정 생성이나 유료 리소스 실행 없이 시작한다.

## 매일 루틴

10분: 어제 내용을 보지 않고 설명 → 25분: 개념 학습 → 20분: 문제·설계 → 5분: 기록.
90분이 가능하면 실습 30분을 추가한다. 30분만 가능하면 한 날의 내용을 이틀로 나눈다.
