# 공식 자료와 읽는 방법

시험 안내·시험 가이드 확인일: 2026-09-16. 서비스 문서는 각 단원 학습 시 최신 내용을 확인하는 참고 링크다. 링크가 있다는 것만으로 모든 하위 문서와 유료 강의를 검토했다는 뜻은 아니다.

## 자격증

- [SAA 시험 안내](https://aws.amazon.com/certification/certified-solutions-architect-associate/): 형식·응시료·언어·준비 자료.
- [SAA-C03 가이드](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html): 영역과 세부 과제, 범위 안/밖 서비스.
- [CLF-C02 가이드](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html): 기초 학습 범위.
- [AI Practitioner](https://aws.amazon.com/certification/certified-ai-practitioner/): 선택적인 AI 기초 자격증.
- [ML Engineer Associate](https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/): 후속 ML 운영 학습 방향.

## 공부와 실습

- [AWS Skill Builder](https://skillbuilder.aws/): 시험명으로 검색해 공식 준비 경로와 문제 세트를 찾는다. 무료·유료 여부는 각 콘텐츠에서 확인한다.
- [AWS 시작하기](https://aws.amazon.com/getting-started/): 기초와 튜토리얼.
- [AWS 문서](https://docs.aws.amazon.com/): IAM, VPC, EC2, S3, RDS, Lambda 등 서비스별 가이드.
- [공동 책임 모델](https://aws.amazon.com/compliance/shared-responsibility-model/): 서비스에 따른 책임 경계.
- [IAM 가이드](https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html): 정책과 역할.
- [VPC 가이드](https://docs.aws.amazon.com/vpc/latest/userguide/what-is-amazon-vpc.html): 네트워크와 라우팅.
- [S3 가이드](https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html): 객체·버킷·권한·버전.
- [Well-Architected](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html): 설계 검토 관점.
- [가격 계산기](https://calculator.aws/): 사용량을 가정해 예상 비용 계산.
- [Free Tier](https://aws.amazon.com/free/): 현재 플랜과 혜택 조건.

읽기 순서: 개념 요약 → 서비스 선택 예시 → 공식 문서에서 조건 확인 → 내 프로젝트에 적용 → 오답 기록.
