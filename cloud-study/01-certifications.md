# 어떤 자격증을 취득할까

## 개인화한 추천

AI 전공이며 분류 모델을 학습해본 상황에서는 모델을 저장하고 API로 서비스하며 권한·네트워크·비용을 관리하는 지식이 도움이 된다. 따라서 **기초 공부 → SAA → 배포 프로젝트**를 우선한다. 아래 우선순위는 개인화한 제안이지 공식 추천 순위가 아니다.

| 자격증 | 배울 내용 | 이 계획에서의 위치 |
|---|---|---|
| Cloud Practitioner, CLF-C02 | 클라우드 개념·보안·주요 서비스·과금 | 기초 학습 필수, 시험 응시는 선택 |
| Solutions Architect – Associate, SAA-C03 | 보안·복원력·성능·비용을 고려한 설계 | 주 취득 목표 |
| AI Practitioner, AIF-C01 | AI 활용과 AWS AI 서비스에 대한 기초 이해 | 빠른 AI 기초 자격증이 필요할 때 선택 |
| Machine Learning Engineer – Associate | ML 워크로드 구현과 운영 | AWS 실습 경험 이후 검토 |

자격증을 모두 순서대로 취득할 필요는 없다. AWS 자체가 처음이고 기초 확인이 필요하면 CLF부터, 기초 설명과 실습이 가능하면 SAA 준비에 집중한다. SAA 공식 대상자는 약 1년의 설계 실무 경험을 권장하므로 초보자가 8주 내 어렵다면 일정을 늘린다.

## 확인한 SAA 시험 정보

- 현재 확인한 코드: SAA-C03.
- 65문항, 130분, 단일·복수 응답.
- 기본 응시료 150 USD. 실제 통화·세금·결제액은 예약 화면 확인.
- 한국어 제공, 유효기간 3년.
- 환산 합격점 720/1,000. 정답률 72%라는 의미가 아니다.
- 영역: 보안 30%, 복원력 26%, 고성능 24%, 비용 최적화 20%.

[공식 시험 안내](https://aws.amazon.com/certification/certified-solutions-architect-associate/) · [시험 가이드](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html)

## 기초 공부의 범위

CLF-C02는 클라우드 개념 24%, 보안·규정 준수 30%, 기술·서비스 34%, 과금·가격·지원 12%로 구성된다. 기초 설명을 다루며 구현 실력을 직접 증명하는 시험으로 해석하지 않는다.

[CLF 공식 가이드](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html)

## 시험 예약 전 자체 기준

- 처음 보는 연습문제에서 정답뿐 아니라 오답 이유를 설명한다.
- 약한 영역을 확인하고 다른 문제로 다시 점검한다.
- 시간 제한 아래 문제를 끝낼 수 있다.
- 최신 공식 가이드의 범위를 빠짐없이 점검한다.
- 모의 정답률은 준비도 참고값이며 실제 환산점수나 합격을 보장하지 않는다.
