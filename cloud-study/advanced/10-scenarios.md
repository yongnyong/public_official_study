# 10장. 심화 시나리오 20문항

<details>
<summary>정답·모든 선택지 해설·복습 포인트</summary>

## Q20. 안전한 점진 배포

새 모델을 점진 배포할 때 적절한 두 조치는?

A. 배포 전 중단 기준과 관찰 지표 정의

B. 모델·전처리·DB 스키마의 롤백 호환 확인

C. 트래픽 1%면 모든 희귀 오류를 반드시 발견

D. 정답이 없는데 즉시 정확도 향상 확정

<details>
<summary>정답·모든 선택지 해설·복습 포인트</summary>

**정답: A, B**

- **A:** 결과를 본 뒤 기준을 임의로 바꾸는 것을 피하고 객관적 판단 근거를 마련한다.

- **C:** 표본이 작으면 드문 오류를 놓칠 수 있다.
- **D:** 정답이 늦게 오는 서비스는 대리 지표와 사후 평가를 구분해야 한다.

## 오답 활용

계산 문제는 단위를 붙여 다시 풀고, 정책 문제는 요청 주체를 적는다. 네트워크 문제는 왕복 경로, 데이터 문제는 시간순 상태 변화를 그린다. 정답 문자를 암기했다면 조건을 한 개 바꾸고 답이 유지되는지 설명한다.
