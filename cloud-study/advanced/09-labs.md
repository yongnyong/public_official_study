# 9장. 실행 실험 6개

[목차](README.md)

Python 3.10 이상, 추가 패키지 불필요. AWS 연결·과금·네트워크 요청·파일 쓰기가 없는 실험이다. SQLite도 메모리에서만 사용한다. 실제 AWS 서비스의 에뮬레이터나 운영용 코드가 아니다.

## 실행 방법

저장소를 내려받아 PowerShell에서 저장소 루트로 이동한다. GitHub 페이지의 코드 블록을 클릭하는 것만으로 실행되지는 않는다.

```powershell
python cloud-study/advanced/labs/experiments.py
python -m unittest discover -s cloud-study/advanced/labs -p "test_*.py" -v
```

첫 명령은 학습 출력, 두 번째는 경계 조건 검증이다. `python` 대신 `py`가 설치된 환경은 명령을 바꿔 사용할 수 있다.

## 실험 1. 가장 구체적인 경로

예상 출력: `10.20.5.12 → inspection`, `10.20.8.12 → peer`, `8.8.8.8 → default`.

직접 변경: /24 경로를 제거하고 첫 주소가 peer로 바뀌는지 확인한다. 리스트 순서를 뒤집어도 다른 길이의 접두사 선택은 같아야 한다.

한계: 동일 접두사의 AWS 라우트 유형별 우선순위를 구현하지 않았다. 동일 최장 길이가 둘이면 오류를 낸다. 이 제한을 실제 AWS 동작으로 오해하지 않는다.

## 실험 2. 큐 적체

도착량 `[8,8,20,20,0,0]`, 초당 용량 10의 각 초말 잔량은 `[0,0,10,20,10,0]`이다. 각 초에 먼저 도착하고 그 다음 처리한다는 이산 모델이다.

과제: 용량을 5로 바꾸고 마지막에 적체가 남는지 확인한다. 누적 입력 = 누적 완료 + 남은 작업이라는 보존식을 검증한다. 실제 처리 시간 분포·실패·재시도는 이 모델에 없다.

## 실험 3. 평균과 꼬리 지연

95건×100ms, 5건×3000ms에서 평균 245ms, nearest-rank p95=100ms, p99=3000ms.

과제: 느린 요청을 6개로 늘리면 p95가 어떻게 바뀌는가? 측정 도구가 사용하는 percentile 정의를 기록해야 하는 이유를 설명한다.

## 실험 4. 가상 가격 손익분기

3,000,000건에서 A·B 비용이 같아진다. 1,000,000건에서는 A=22, B=10. 5,000,000건에서는 A=30, B=42. 단위는 가상 비용 단위다.

과제: 로그 비용을 요청당 0.000001 추가하면 어느 방식이 달라지는지 명시하고 다시 계산한다. 양쪽에 똑같이 추가하면 교차점은 같을 수 있다.

## 실험 5. 트랜잭션과 중복 기록

첫 실행은 INSERT 후 commit 전에 예외를 일으킨다. 결과 행 수는 0이어야 한다. 다음 실행은 created, 이미 commit된 뒤 재전달을 가정한 실행은 duplicate다. 동일 작업 ID에 다른 모델 버전을 넣으면 오류다.

중요한 한계:

- 같은 프로세스의 메모리 DB로 실습하므로 프로그램 종료 후 기록은 유지되지 않는다.
- 예외 rollback을 보여주며 OS 강제 종료의 모든 동작을 시험하지 않는다.
- 다중 워커 경쟁·분산 잠금·외부 이메일 발송의 원자성을 해결하지 않는다.
- 스코어는 특징 합계인 장난감 함수이며 학습된 ML 모델이 아니다.

심화 과제: 결과 저장과 외부 알림 사이에 실패하면 무엇이 남는지 상태표를 작성한다. DB 트랜잭션만으로 외부 알림을 되돌릴 수 없다는 점을 설명한다.

## 실험 6. 재시도 간격 분산

jitter가 없으면 `[1,2,4,8,8]`이다. A·B 워커는 서로 다른 고정 분수를 사용해 다른 간격을 출력한다. 실제 random 대신 재현 가능한 분수로 원리를 보여준다. 실제 sleep은 하지 않는다.

과제: 대기시간 상한을 2로 바꾸고 이후 간격이 어떻게 제한되는지 확인한다. 재시도 횟수 5는 첫 시도 외 추가 대기 5번이라는 이 실험의 정의다.

## 실험 보고서

각 실험에 예상 → 실제 → 변경 입력 → 관찰 → 실제 시스템과의 차이를 적는다. 테스트가 통과했다고 운영 환경의 가용성이나 보안을 증명한 것은 아니다.
