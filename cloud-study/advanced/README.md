# 클라우드 심화 학습실 — 기초 다음 단계

작성일: 2026-09-16. 기존 상세 교재를 끝낸 학습자를 위한 후속 과정이다. SAA 수준의 설계 판단을 중심으로 하며 분산 처리·운영 실험은 이해를 돕는 심화 내용이다. 이 과정이 별도 Professional 자격증 대비 전체 과정이라는 뜻은 아니다.

## 학습 결과

서비스 이름을 고르는 수준에서 다음 수준으로 이동한다.

- 요청 주체·경로·데이터 일관성을 추적해 실패 원인을 좁힌다.
- 여러 정답 후보에서 요구사항을 어기는 조건을 찾는다.
- 트래픽·복구·비용을 수치로 계산하고 가정을 명시한다.
- 재시도·중복·캐시·배포의 경계 조건을 실험한다.
- 실제로 측정한 결과와 설계상 기대를 구분한다.

## 시작 방법

오늘은 1장을 읽고 요청별 판정표를 직접 작성한다. 내일 2장의 경로 그림을 그린다. 각 장을 60~120분으로 배분하되 계산과 실험이 막히면 이틀에 나눠 진행한다. 학습 기간은 권장 일정이며 실력 보장 기간이 아니다.

모든 연습 수치·회사·계정은 가상이다. 객관식은 자체 제작이며 실제 시험 문제·공식 난도·합격 예측을 주장하지 않는다. 실제 AWS 자원은 생성하지 않는다. 각 장의 공식 참고 링크는 상세 조건을 확인하는 데 사용한다.
