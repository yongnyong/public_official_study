### 상세 교재에서 실제로 다루는 예제

| 단원 | 직접 계산·추적하는 내용 |
|---|---|
| Python | 평균·분산 계산, 리스트 공유와 복사 |
| 선형대수 | 행렬 곱으로 예측 만들기, 잔차와 MSE |
| 미분 | 경사하강법 3회 갱신, 큰 학습률의 진동 |
| 확률 | 1만 건 빈도표로 베이즈 정리 계산 |
| 알고리즘 | 큐의 변화를 따라 BFS와 최단거리 구하기 |
| DB | 학생·수강 테이블의 JOIN과 집계, 정규화 |
| OS | 두 스레드의 갱신 충돌, LRU 교체 과정 |
| 머신러닝 | 혼동행렬에서 정확도·정밀도·재현율·F1 |
| 딥러닝 | 뉴런 하나의 순전파·역전파·가중치 갱신 |
| Attention | 점수 → softmax → Value 가중합 |
| 보안·RAG | 인증·인가, 검색 실패와 생성 실패 구별 |

**추천 순서: Python → 선형대수·미적분·확률 → 자료구조·SQL → 머신러닝 → 딥러닝 → 프로젝트.** 수학을 전부 끝낼 때까지 코딩을 미루지 말고 병행한다. 공무원 진로는 전산개발과 데이터 직류를 비교하면서 결정한다.

이 자료는 독학을 위한 핵심 개념 정리와 학습 설계다. 대학 강의 전체나 수험 기본서를 대체하지 않는다. 전공 지식, 시험에 직접 연결되는 지식, 심화 내용을 구분했다. 현재 수준을 모르는 상태이므로 기초부터 시작하되 진단문제를 풀 수 있으면 해당 단계를 줄인다.
