# 한국사능력검정시험 심화 1급 학습실

작성·시험 제도 확인: 2026-09-18.

심화 신청 후 **흐름 이해 → 시대 구분 → 사료 단서 해석 → 기출 선지 분석** 순서로 공부하는 독학 자료다. 목표는 **1급(80점 이상)**이다. 실제 시험일은 아직 확인되지 않았으므로 하루 90분·28일을 기본안으로 둔다. 수강 강좌의 차시를 그대로 옮긴 자료가 아니라 독자적으로 구성한 학습 노트다.

## 바로 시작하기

1. 아래 시험 안내를 읽고 접수 내역에서 회차·일시·시험장을 확인한다.
2. [연습문제](08-practice.md) 중 1~5번을 먼저 풀어 현재 수준을 점검한다.
3. [선사·고대](02-ancient.md)를 읽고 책을 덮은 채 나라별 단서 세 개를 적는다.
4. [28일 계획](01-plan.md)의 1일 차부터 진행한다.
5. 틀린 문제뿐 아니라 맞혔어도 근거를 설명하지 못한 문제를 [오답 기록](09-review-log.md)에 남긴다.

## 심화 시험의 기준

- 심화는 50문항, 5지선다형이며 시험 시간은 80분이다.
- 점수에 따라 **1급 80점 이상 / 2급 70~79점 / 3급 60~69점**으로 인증한다.
- 문항 배점은 1·2·3점이므로 정답 개수만으로 점수를 계산하지 않는다.
- 심화는 한국사의 흐름과 주요 개념뿐 아니라 자료 해석과 시대적 쟁점 파악을 평가한다.
- 위 내용의 근거: [공식 시험 안내](https://www.historyexam.go.kr/pageLink.do?link=examGuideline), [공식 시험 시간 안내](https://www.historyexam.go.kr/pageLink.do?link=apyexmInfo).
- 실제 응시 시간·준비물·입실 기준은 본인 회차의 공식 응시요강과 수험표를 최종 확인한다.

## 목표 설정

1급을 목표로 전 범위를 공부하며, 첫 기출 점수로 진도를 조정한다. 1급 대비 연습 목표는 처음 보는 최근 기출에서 85점 이상을 반복해 얻는 것으로 잡을 수 있다. 이는 학습용 권장 목표이며 합격 보장이나 공식 기준이 아니다.

이 교재의 자체 제작 문제는 개념 확인용이다. 실제 시험의 사진·지도·사료 길이와 난도를 대신하지 않으므로 공식 기출을 반드시 함께 푼다. 기출 원문과 사진은 재배포하지 않고 공식 자료실로 연결한다.
