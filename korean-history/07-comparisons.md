# 07. 1급을 위한 비교표와 자료 해석

[전체 목차](README.md)

## 1. 같은 기능, 다른 시대

| 주제 | 고려 | 조선 |
|---|---|---|
| 감찰 | 어사대 | 사헌부 |
| 국립 교육 | 국자감 | 성균관 |
| 지방 큰 틀 | 5도 양계 | 8도 |
| 관리 토지 | 전시과 | 과전법→직전법→관수관급제 |
| 역사서 | 삼국사기·삼국유사 | 고려사·조선왕조실록·동국통감 |

국자감 설치는 고려 성종, 국학 설치는 통일신라 신문왕이다. 유교 교육 기관이라는 공통점 때문에 주체를 바꾸는 선지에 주의한다. 과전법은 고려 말에 시작되어 조선으로 이어진 제도다.

## 2. 문화사 연결표

| 분야 | 자료·인물 | 시대·핵심 |
|---|---|---|
| 역사 | 삼국사기 | 고려 김부식, 기전체 |
| 역사 | 삼국유사 | 고려 일연, 불교·설화·단군 |
| 역사 | 제왕운기 | 고려 이승휴, 운문 |
| 역사 | 동국통감 | 조선 성종 때 완성, 편년체 |
| 지리 | 동국여지승람 | 조선 성종, 지리지 |
| 지리 | 대동여지도 | 조선 후기 김정호 |
| 농업 | 농사직설 | 세종, 우리 풍토의 농법 |
| 의학 | 동의보감 | 허준, 광해군 때 간행 |
| 천문 | 칠정산 | 세종, 역법 |
| 인쇄 | 직지 | 고려, 1377년 금속활자본 |

기전체는 인물 중심의 본기·열전 등으로 구성하고, 편년체는 연월 순으로 서술한다. 역사서 이름만 외우지 말고 서술 방식과 저자를 한 세트로 학습한다.

## 3. 유적·지역은 사건과 함께

| 지역 | 연결할 소재 |
|---|---|
| 공주·부여 | 백제 웅진·사비, 무령왕릉·정림사지 |
| 익산 | 미륵사지, 백제 문화 |
| 경주 | 신라·통일신라, 불국사·석굴암 |
| 강화 | 고려 대몽 항쟁, 외규장각, 병인·신미양요, 강화도 조약 |
| 수원 | 정조, 화성·장용영 |
| 동학 관련 전북 지역 | 고부·황토현·전주, 농민 운동 |
| 대구 | 국채보상운동 |
| 광주 | 1929 학생 항일 운동, 1980 민주화운동 |
| 청주 | 흥덕사, 직지 |
| 충칭 | 대한민국 임시정부, 한국광복군 |

같은 지역에 여러 시대가 겹친다. '강화도'만 보고 병인양요를 선택하지 말고 몽골·프랑스·미국·운요호 등 추가 단서로 좁힌다. 유적 사진은 공식 기출에서 실제 모습을 확인한다.

## 5. 사료 문제를 푸는 5단계

1. **무엇을 묻는지 읽기**: 인물인지, 시기인지, 결과인지, 옳지 않은 것인지 확인한다.
2. **단서 두 개 찾기**: 고유명사·관직·연호·지명·구호를 표시한다.
3. **시대 범위 잡기**: 한 단어에 확신하지 말고 두 단서의 교집합으로 좁힌다.
4. **선지의 주어·행동·시점 검토**: 사실인 문장도 질문의 대상과 다르면 오답이다.
5. **남은 선지 비교**: 가장 구체적이고 배타적인 근거를 찾아 선택한다.

### 자체 제작 예시 A

'억울하게 노비가 된 사람을 조사해 양인으로 돌리고, 쌍기의 건의를 받아 시험으로 관리를 뽑았다.'

노비안검법+과거제→고려 광종이다. 성종의 12목 지방관 파견이나 태조의 사심관은 같은 고려 전기라도 광종의 정책이 아니다. 이 문장은 설명용으로 새로 만든 것이며 사료 원문 인용이 아니다.

### 자체 제작 예시 B

'정부에 내던 특산물 대신 토지 결수에 따라 쌀 등을 내게 하고, 필요한 물품은 공인을 통해 마련하였다.'

공납+토지 결수+공인→대동법이다. '군포를 1필로'는 균역법, '전세 4~6두'는 영정법이다. 셋 다 조선 후기라는 이유만으로 고르면 안 된다.

### 자체 제작 예시 C

'호헌 철폐와 직선제 개헌을 요구하며 학생뿐 아니라 넥타이 차림의 시민도 참여하였다.'

1987년 6월 민주 항쟁이다. 3·15 부정선거는 4·19의 계기, 계엄군의 광주 진압은 5·18의 맥락이다.

## 6. 지도·사진·통계 자료

지도에서는 제목·범례·이동 방향·도시 이름을 먼저 본다. 독립운동 지도는 서간도·북간도·연해주·상하이·충칭을 구별한다. 문화재 사진은 명칭을 가리고 재료·구조·양식을 관찰한 뒤 시대를 확인한다. 통계는 증가·감소만 보지 말고 단위·연도·집계 대상을 확인한다.

## 7. 1급 실전 점검

- 개념을 아는 것과 80분 동안 자료를 읽고 마킹하는 능력을 따로 점검한다.
- 80분 연습의 예: 1차 풀이 55분, 보류 문제 15분, 마킹 확인 10분. 개인 속도에 맞춰 조정한다.
- 어려운 문제 하나에 오래 머무르면 전체 점수에 손해가 난다. 표시 후 돌아오는 연습을 한다.
- 맞혔지만 설명하지 못한 문제도 취약점으로 기록한다.
- 처음 보는 최근 기출 3회에서 85점 이상을 반복하는 것을 권장 학습 목표로 삼는다. 공식 합격 기준은 80점이며, 이 연습 목표가 합격을 보장하지는 않는다.
