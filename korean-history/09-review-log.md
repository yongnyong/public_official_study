## 작성 예시 — 자체 제작 예제

- 대상: 대동법
- 단서: 토지 결수, 공인
- 틀린 원인: 공납과 군역 혼동
- 교정: 대동법은 공납 개편이고, 균역법은 군포를 1필로 줄인 군역 개편이다.
- 재확인: 세 제도의 대상을 보지 않고 쓴다.

## 시험 전 체크

- [ ] 본인 회차의 공식 응시요강과 입실 마감 시각 확인
- [ ] 수험표·인정 신분증 및 공식 안내의 준비물 확인
- [ ] 시험장 위치와 이동 시간 확인
- [ ] 기출 배점 합산과 제한 시간 연습
- [ ] 반복 오답 10개와 주요 연표 복습
- [ ] 실제 성적과 추측으로 맞힌 문제를 구분

접수번호·신분증·집주소 같은 개인정보는 학습 기록에 적을 필요가 없다.
