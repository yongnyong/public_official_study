# 24주 기초 학습 계획

주당 12시간 가정: 전공 이론·계산 5시간, 구현·실습 3시간, 복습·서술 2시간, 공무원 진로·공통 준비 탐색 2시간. 공채 응시를 확정하거나 시험이 가까워지면 공통 준비와 기출에 별도 시간을 늘려야 한다. 이 배분은 합격용 시간표가 아니라 전공을 중심으로 진로를 병행하는 입문 시간표다.

주당 6시간이면 약 48주로 늘리고, 이미 익힌 단원은 완료 기준을 통과한 뒤 압축한다. 밀린 진도를 무리하게 합치지 말고 4주마다 계획을 조정한다.

## 4주마다 다음 단계 진입 기준

- 4주: 리스트·함수로 짧은 프로그램을 쓰고 행렬곱과 미분 한 문제를 푼다.
- 8주: 베이즈와 복잡도를 설명하고 BFS를 추적한다.
- 12주: SQL 조인을 쓰고 선형·로지스틱 회귀의 차이를 설명한다.
- 16주: 누수 없이 전처리를 구성하고 과적합을 학습곡선으로 해석한다.
- 20주: attention과 전통 AI의 기초를 설명하고 보안 개념을 구별한다.
- 24주: 새 환경에서 프로젝트를 재현하고 한계와 진로별 추가 과제를 적는다.

못 넘은 기준은 다음 주의 새 이론 시간을 줄여 보완한다. 수학에서 막히면 전체 과정을 멈추기보다 필요한 계산 예제로 돌아간다.

## 평일·주말 운영 예

평일 4일×1.5시간: 개념 40분, 손계산/구현 40분, 회상 10분. 주말 6시간: 프로젝트 3시간, 문제·복습 1시간, 공고·공통 준비 2시간. 하루는 쉬거나 밀린 내용만 처리한다.

## 24주 이후

- 데이터 관심: AI의 탐색·추론·학습 전 범위, 정보보호, DB를 기출 기준으로 심화한다.
- 전산개발 관심: 자료구조의 정확성·복잡도, DB 동시성·회복, OS 계산·동기화를 심화한다.
- 전공 심화 관심: 확률·선형대수를 보강하고 관심 분야 강의 하나와 논문 재현 하나를 선택한다.
- 공채 지원 확정: 지원 연도 공고를 확인하고 공통 평가·검정요건·기출·면접을 포함한 별도 수험 계획을 만든다.
