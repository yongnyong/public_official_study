# 진단·서술형 연습 20문제

아래는 학습용 자체 제작 문제다. 실제 기출이나 공식 채점기준이 아니다. 먼저 해설을 가리고 푼다. 문제마다 ‘설명 가능 2점 / 일부만 가능 1점 / 모름 0점’을 기록한다. 총점은 합격 예측이 아니라 공부 시작점을 찾기 위한 값이다.

## 문제

1. X가 20×4, w가 4×1일 때 Xw의 크기는? 절편은 어떻게 더하는가?
2. L(w)=(w−3)²에서 w=0, 학습률 0.1로 한 번 갱신하라.
3. P(A)=0.1, P(B|A)=0.8, P(B|A의 여집합)=0.2일 때 P(A|B)는?
4. 리스트 [1,2,3]의 평균과 모집단 분산을 구하라.
5. 상관계수 0이면 두 변수는 반드시 독립인가?
6. 정렬된 배열에서 이진탐색이 O(log n)인 이유를 설명하라.
7. BFS가 최단경로를 구하는 조건과 사용하는 자료구조는?
8. 해시 테이블과 균형 이진탐색트리를 동등·범위 검색 관점에서 비교하라.
9. 학생번호→학생이름인 수강 테이블에서 이름을 반복 저장하면 생기는 문제는?
10. COUNT(*)와 COUNT(score)는 score가 NULL일 때 어떻게 다른가?
11. 프로세스와 스레드의 차이 및 스레드 동기화가 필요한 이유는?
12. 교착상태 네 필요조건을 쓰고 예방과 회피를 비교하라.
13. sigmoid(0)은? 로지스틱회귀는 이름과 달리 어떤 문제에 흔히 쓰이는가?
14. TP=40, FP=10, FN=20일 때 precision·recall·F1을 구하라.
15. 전체 데이터로 표준화한 다음 교차검증하면 왜 문제가 되는가?
16. 훈련오차가 계속 줄고 검증오차가 증가하면 무엇을 점검할 것인가?
17. 선형층 두 개를 활성화 없이 쌓으면 표현력이 어떻게 되는가?
18. Q,K가 10×8, V가 10×6이면 QKᵀ와 attention 출력의 크기는?
19. 암호화·해시·전자서명의 목적 차이를 설명하라.
20. RAG를 적용하면 환각이 사라지는가? 평가를 어떻게 나눌 것인가?

## 정답과 핵심 해설

1. 20×1. 스칼라 절편을 각 샘플 예측에 더하거나 X에 1로 된 열을 추가하고 w를 확장한다.
2. 미분값 −6, 새 w=0.6. 손실은 9→5.76.
3. 0.08/(0.08+0.18)=4/13≈0.3077. 분모에 여집합의 기여도 포함한다.
4. 평균 2, 분산 ((1−2)²+(2−2)²+(3−2)²)/3=2/3. 불편 표본분산은 분모가 n−1이라 1이다.
5. 아니다. 예를 들어 0을 중심으로 대칭 분포인 X에 대해 Y=X²는 X에 의존하지만 적절한 적률 조건에서 공분산은 0이다.
6. 매 단계 후보 구간이 절반으로 줄어 n/2^k≈1이므로 k≈log₂n. 인덱스 접근이 가능한 정렬 배열을 가정한다.
7. 무가중 또는 모든 간선 비용이 같은 그래프의 간선 수 기준. 큐를 사용해 시작점에서 가까운 층부터 방문한다.
8. 해시는 적절한 조건에서 평균 O(1) 동등 검색, 정렬 순서를 직접 제공하지 않아 범위 검색에는 불리하다. 균형 트리는 동등 검색 O(log n), 범위 출력 k개는 구조에 따라 O(log n+k)로 처리할 수 있다.
9. 이름 변경 때 여러 행을 수정해야 하고 일부만 바꾸면 불일치가 생긴다. 학생과 수강을 분리한다. 키와 함수 종속을 명시해야 정규화 이유를 설명할 수 있다.
10. COUNT(*)는 행 수, COUNT(score)는 NULL이 아닌 score 개수다.
11. 프로세스는 자원 관리 단위, 스레드는 실행 흐름이다. 같은 프로세스의 스레드는 주소 공간 등을 공유하므로 경쟁 상태를 제어해야 한다.
12. 상호배제·점유와 대기·비선점·순환대기. 예방은 조건 하나를 깨고 회피는 할당 전 안전 상태를 검토한다.
13. 0.5. 대표적으로 이진 분류. 출력 확률과 최종 클래스 결정 임계값을 구별한다.
14. precision=40/50=0.8, recall=40/60≈0.6667, F1=80/110≈0.7273.
15. 검증 부분의 통계가 훈련 처리에 반영된다. 각 fold의 훈련 부분에서 전처리를 학습하고 검증 부분에는 적용만 한다.
16. 과적합 가능성을 점검한다. 분할 적절성·데이터 품질을 먼저 보고 정규화·복잡도 감소·조기 종료 등을 검증한다. 현상 하나만으로 원인을 확정하지 않는다.
17. W₂(W₁x+b₁)+b₂=(W₂W₁)x+(W₂b₁+b₂)이므로 하나의 아핀 변환으로 합쳐진다.
18. QKᵀ는 10×10, 그 가중치와 V를 곱한 출력은 10×6. 각 query가 key 위치에 주는 가중치를 계산한다.
19. 암호화는 기밀성, 해시는 고정 길이 요약, 서명은 개인키로 생성하고 공개키로 검증하는 무결성·서명자 인증에 쓰인다. 일반 해시만으로 송신자 인증이 되지 않는다.
20. 아니다. 검색 단계의 근거 문서 포함 여부와 생성 단계의 정확성·근거 일치를 나눠 평가하고 근거가 없을 때 응답 보류도 점검한다.

## 서술형 답안 틀

정의 → 동작 원리·수식 → 예시·계산 → 조건·한계 순으로 작성한다. 비교 문제는 동일 기준(성능, 비용, 보장 조건 등)을 양쪽에 적용한다. 계산은 최종 숫자만 쓰지 않고 가정과 중간 단계를 남긴다.

예시 질문: ‘데이터 누수의 의미와 방지 방법을 설명하라.’

예시 답안: 데이터 누수는 실제 예측 때 사용할 수 없는 정보나 평가 데이터의 정보가 모델 학습·선택 과정에 들어가는 현상이다. 전체 데이터의 평균으로 결측값을 대치한 뒤 교차검증하면 검증 데이터의 분포가 전처리에 반영된다. 각 fold의 훈련 데이터에서 대치 규칙을 학습하고 검증 데이터에는 적용만 해야 한다. 반복 관측은 그룹 분할, 미래 예측은 시간 분할을 검토하며 테스트 데이터는 최종 평가를 위해 보존한다.

## 복습 규칙

오답은 답을 옮겨 쓰기보다 ‘틀린 이유 한 문장 + 바꾼 숫자로 다시 풀기’를 남긴다. 다음 날, 1주 뒤, 4주 뒤에 다시 설명한다. 정의를 외웠어도 조건을 빠뜨리면 미완료로 표시한다.
