# 인공지능에 필요한 수학

## 1. 선형대수: 데이터를 벡터로 다루는 언어

| 개념 | 이해할 내용 | AI에서 쓰는 곳 |
|---|---|---|
| 벡터·내적 | 방향·크기와 성분별 곱의 합 | 유사도, 선형 예측 |
| 행렬 곱 | 입력의 선형 변환, 곱셈 순서 | 신경망 층, 배치 계산 |
| 선형독립·랭크 | 중복되지 않는 정보의 차원 | 회귀 해의 유일성 |
| 직교·투영 | 부분공간 위의 가장 가까운 점 | 최소제곱 |
| 고유값·고유벡터 | 변환 후 방향이 유지되는 축 | 공분산 분석 |
| SVD | 행렬을 직교 방향과 스케일로 분해 | PCA, 저랭크 근사 |
| 양의 준정부호 | 모든 x에 대해 xᵀAx ≥ 0 | 공분산, 볼록 이차함수 |

샘플 n개, 특성 d개라면 X는 n×d, 가중치 w는 d×1, 예측 Xw는 n×1이다. 수식을 볼 때 차원부터 적으면 구현 오류를 줄일 수 있다.

예: X=[[1,2],[3,4]], w=[2,1]이면 Xw=[4,10]. 행렬 곱은 성분별 곱과 다르다.

최소제곱은 잔차의 제곱합을 최소화한다. X의 열이 선형독립일 때 w=(XᵀX)⁻¹Xᵀy로 표현할 수 있다. 실제 계산에서는 역행렬을 직접 만들기보다 적절한 선형시스템 풀이·QR·SVD를 사용한다. 열들이 중복되면 이 역행렬 식을 그대로 쓸 수 없다.

PCA는 중심화한 데이터에서 분산이 큰 직교 방향을 찾는다. 큰 분산이 항상 예측에 중요한 정보라는 뜻은 아니다. 특성 단위가 다르면 표준화 여부가 결과를 크게 바꾼다.

## 2. 미적분: 손실을 줄이는 방향

- 도함수: 한 변수의 순간 변화율.
- 편미분: 다른 변수를 고정하고 특정 변수만 바꿀 때의 변화율.
- 그래디언트 ∇L: 모든 편미분을 모은 벡터. 작은 이동에서 가장 빠르게 증가하는 방향이다.
- 연쇄법칙: 합성함수의 미분을 연결한다. 역전파의 핵심이다.
- 헤시안: 2차 편미분 행렬. 곡률과 최적점 분석에 사용한다.

경사하강법: w_next = w − η∇L(w). η는 학습률이다. 학습률이 너무 크면 진동·발산할 수 있고 너무 작으면 학습이 느리다. 비볼록 신경망에서 전역 최적해를 보장하는 식은 아니다.

예: L(w)=(w−3)², w=0이면 미분값은 −6. η=0.1에서 한 번 갱신하면 w=0.6이고 손실은 9에서 5.76으로 감소한다.

L(w)=||Xw−y||²/n이면 ∇L=2Xᵀ(Xw−y)/n이다. 1/2을 손실에 붙이면 미분의 2가 사라지므로 정의부터 확인한다.

## 3. 확률·통계: 불확실성을 다루는 언어

| 개념 | 의미와 주의점 |
|---|---|
| 조건부확률 | P(A|B)=P(A∩B)/P(B), P(B)>0 |
| 독립 | P(A∩B)=P(A)P(B). 상관계수 0만으로 일반적인 독립을 보장하지 않음 |
| 베이즈 정리 | P(A|B)=P(B|A)P(A)/P(B). 사전확률을 증거로 갱신 |
| 기댓값·분산 | 평균 위치와 퍼짐. Var(X)=E[X²]−E[X]² |
| 공분산 | 두 변수의 함께 변하는 정도. 단위에 영향을 받음 |
| 확률분포 | 베르누이·이항·정규를 먼저, 다항·포아송·지수는 다음 |
| MLE | 관측 데이터의 우도를 최대화하는 파라미터 추정 |
| MAP | 우도에 사전분포를 반영해 사후확률 최대화 |
| 신뢰구간 | 반복 표집 절차의 장기적 포함률로 해석 |
| 가설검정 | p값은 귀무가설과 가정 아래 관측값 이상 극단적인 결과의 확률 |

베이즈 예제: 실제 양성 비율 1%, 민감도 90%, 위양성률 5%라면 양성 판정 뒤 실제 양성일 확률은 0.009/(0.009+0.0495)≈15.38%다. 민감도만 보고 양성 판정의 신뢰도를 판단할 수 없다.

중심극한정리는 적절한 조건 아래 표본평균의 분포에 대한 결과다. 원자료가 무조건 정규분포가 된다는 뜻이 아니다. 상관관계만으로 정책의 인과효과를 주장하지 않는다.

## 4. 최적화·정보이론

- L2 정규화: 큰 가중치에 제곱 패널티를 준다. 과적합 완화에 쓰지만 항상 성능이 좋아지는 것은 아니다.
- L1 정규화: 절댓값 패널티. 희소한 해를 유도할 수 있다.
- 볼록함수: 국소 최솟값이 전역 최솟값이다. 신경망 손실은 일반적으로 비볼록이다.
- 엔트로피 H(p)=−Σp log p: 분포의 불확실성.
- 교차엔트로피 H(p,q)=−Σp log q: 실제 분포 p를 예측 q로 표현할 때의 손실.
- KL 발산: 두 분포의 차이를 나타내지만 일반적으로 대칭이 아니므로 거리함수는 아니다.
