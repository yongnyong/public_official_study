# 프로그래밍과 전산학 기초

## 1. Python과 개발 습관

먼저 변수·조건문·반복문·함수·리스트·딕셔너리·집합·파일 입출력·예외를 익힌다. 다음으로 모듈·가상환경·패키지·클래스를 익힌다. AI에서는 NumPy 배열의 shape, dtype, broadcasting과 pandas의 결측치·중복·조인을 이해하는 것이 중요하다.

주의할 점: 리스트를 다른 변수에 대입하면 같은 객체를 가리킬 수 있다. 얕은 복사는 내부의 중첩 객체까지 독립적으로 복사하지 않는다. 표 데이터를 합칠 때 조인 키가 중복이면 행 수가 예상보다 늘어날 수 있다.

Git은 변경 이력을 남기는 도구다. 한 번의 커밋에는 한 가지 학습 결과를 담고, 데이터 원본·비밀번호·토큰은 넣지 않는다. 프로젝트에는 실행 방법, 입력 데이터 출처, 평가 기준을 기록한다.

**연습:** CSV를 읽어 결측치 개수와 그룹별 평균을 출력하고, 잘못된 숫자·빈 파일을 처리한다. 함수마다 입력·출력 예시를 적는다.

## 2. 자료구조·알고리즘

| 주제 | 핵심 원리 | 손으로 할 연습 |
|---|---|---|
| 배열·연결리스트 | 인덱스 접근과 삽입·삭제 비용의 차이 | 작업 위치별 비용 비교 |
| 스택·큐 | LIFO·FIFO | 괄호 검사·BFS 추적 |
| 해시 테이블 | 키를 버킷에 대응, 충돌 처리 | 체이닝·개방주소법 비교 |
| 탐색 트리 | 키 순서와 트리 높이 | 삽입·삭제·회전 |
| 힙 | 최솟값/최댓값 우선 접근 | 삽입·삭제·힙 정렬 |
| 그래프 | 정점·간선, 인접리스트/행렬 | BFS·DFS 방문 순서 |
| 최단경로 | 가중치 조건에 따라 알고리즘 선택 | Dijkstra·Bellman–Ford |
| 동적계획법 | 상태·점화식·초깃값·계산 순서 | 배낭·최장 공통 부분수열 |
| 정렬 | 비교 횟수·안정성·추가 메모리 | 병합·퀵·힙 비교 |

대표 복잡도: 이진탐색 O(log n), 병합정렬 O(n log n), 인접리스트 BFS O(V+E). 균형을 보장하지 않는 이진탐색트리는 최악 O(n)이다. 해시 탐색 평균 O(1)은 적절한 해시와 부하율 등의 가정이 필요하고 최악은 O(n)일 수 있다. 퀵정렬은 평균 O(n log n), 최악 O(n²)이다.

Dijkstra는 음수 가중치가 없는 경우에 사용하는 기본 알고리즘이다. BFS는 무가중 그래프의 간선 수 기준 최단경로를 구한다. 답안에는 알고리즘 이름뿐 아니라 적용 조건을 적는다.

## 3. 데이터베이스

- 관계형 모델: 테이블·튜플·속성, 후보키·기본키·외래키.
- SQL: SELECT, WHERE, JOIN, GROUP BY, HAVING, 서브쿼리, 윈도 함수.
- 함수 종속 X→Y: 같은 X가 같은 Y를 결정한다.
- 정규화: 중복에 따른 갱신·삽입·삭제 이상을 줄인다. 분해의 무손실성과 종속성 보존을 함께 검토한다.
- 3NF: 비자명한 함수 종속 X→A에 대해 X가 슈퍼키이거나 A가 주요 속성인 조건.
- BCNF: 모든 비자명한 함수 종속의 결정자가 슈퍼키여야 한다. BCNF 분해가 항상 모든 종속성을 보존하는 것은 아니다.
- 인덱스: 조회를 돕지만 공간과 쓰기 비용이 추가된다. B+트리는 범위 검색에 적합하고 해시 인덱스는 일반적으로 동등 검색에 적합하다.
- 트랜잭션 ACID: 원자성·일관성·격리성·지속성. 일관성은 선언된 제약과 올바른 응용 로직에도 의존한다.
- 동시성: dirty read, non-repeatable read, phantom, 직렬가능성, 잠금·MVCC.
- 회복: 로그·체크포인트·WAL의 역할.

예: 수강(학생번호, 과목번호, 학생이름, 성적)에서 학생번호→학생이름이면 복합키의 일부에 이름이 종속된다. 학생 테이블과 수강 테이블로 분리해 이름 중복과 갱신 이상을 줄일 수 있다.

**연습:** 학생·과목·수강 테이블을 설계하고, 과목별 평균과 미수강 학생을 SQL로 찾는다. NULL 비교에는 IS NULL을 사용하고 COUNT(*)와 COUNT(열)의 차이를 설명한다.

## 4. 운영체제·컴퓨터구조

프로세스는 실행 중인 프로그램의 자원 관리 단위이고 스레드는 실행 흐름이다. 같은 프로세스의 스레드는 보통 주소 공간을 공유하므로 동기화가 필요하다.

핵심: 문맥 교환, CPU 스케줄링, 경쟁 상태, 임계구역, mutex·semaphore, 교착상태, 가상메모리, 페이징, 페이지 교체, 파일시스템. 구조 기초로 CPU·캐시·메모리 계층, 지역성, 인터럽트, 병렬성과 동시성의 차이를 배운다.

교착상태의 네 필요조건은 상호배제·점유와 대기·비선점·순환대기다. 예방은 조건을 깨고, 회피는 안전 상태를 유지하며, 탐지·복구는 발생 후 처리한다.

**연습:** 같은 참조열로 FIFO와 LRU 페이지 부재를 계산한다. 도착·실행시간 표에서 FCFS와 RR의 대기·반환시간을 계산한다. OS는 전산개발 진로에서 특히 깊게 공부한다.

## 5. 네트워크와 정보보호

| 개념 | 구별할 내용 |
|---|---|
| TCP·UDP | 신뢰성·순서 제어가 있는 전송과 데이터그램 전송 |
| DNS·HTTP·TLS | 이름 해석, 응용 프로토콜, 전송 중 보호 |
| 인증·인가 | 누구인가와 무엇을 할 수 있는가 |
| 대칭·공개키 암호 | 같은 비밀키와 키 쌍의 역할 |
| 해시·MAC·전자서명 | 요약, 공유키 기반 무결성·인증, 공개키로 검증하는 서명 |
| 보안 목표 | 기밀성·무결성·가용성 |
| 접근통제 | 최소 권한, 역할과 속성 기반 통제 |
| 공격과 방어 | SQL injection→매개변수화 쿼리, XSS→문맥에 맞는 출력 처리 |

암호화와 해시는 다르다. 비밀번호는 복호화 목적의 암호화가 아니라 솔트와 전용 비밀번호 해싱 방법으로 검증하는 설계를 배운다. 세부 구현은 검증된 라이브러리를 사용한다.

데이터 직류 관심자는 암호·접근통제·보안 프로토콜·위험관리까지 확장한다. AI 프로젝트에서는 데이터 접근권한, 로그에 남는 개인정보, 학습데이터 오염과 프롬프트 인젝션도 검토한다.
